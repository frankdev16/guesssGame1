# 🔮 Magic Guesser: The 1 Million Challenge

A high-stakes, progressive number-guessing game built with React. Start with just 4 lives and try to survive the ascent to guessing a number out of 1,000,000!

🎮 **[Play the Live Game Here](PASTE_YOUR_VERCEL_OR_NETLIFY_LINK_HERE)**

## ✨ Features

- **Survival Bank System:** Your unused lives carry over to the next stage.
- **Milestone Bonuses:** Earn extra bonus lives for every 3 stages you clear.
- **Proximity Radar:**
  - 🔥 **Burning:** You are within 10% of the answer.
  - ☁️ **Warm:** You are within 30% of the answer.
  - ❄️ **Cold:** You are too far away.
- **Persistent High Score:** Your best score is saved locally in your browser.

## 🛠️ Tech Stack

- React
- Vite
- Standard CSS (Glassmorphism UI)
